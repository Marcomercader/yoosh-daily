Getting started

Both people need to be signed in to iCloud. One person taps start a pair and shares the 8-character code; the other taps i have a code and enters it.

Help

Photo not showing? Make sure both phones are online and signed in to iCloud, then reopen the app.
Want to start over? Menu → leave pair deletes your photos and lets you pair again.
